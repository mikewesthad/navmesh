About This Lab

RUNTIME NAVMESH MUTATION / PHASER 3 LAB
Live Runtime Navmesh Mutation Playground

This demo is built to make one point obvious: a runtime-editable world should not need a full navmesh rebuild every time a few tiles change. Paint terrain, drop blockers, swap traversal rules, and compare localized accelerated patching against Phaser's default full-grid rebuild on the same 100x100 map.

Accelerated

Accelerated mode stitches tile edits into the existing navmesh instead of rebuilding the whole map.

Move mode sends the brawler to the nearest valid point on the active navmesh and repaths immediately after edits.
Land and water use a 2x2 brush so the shoreline tiles stay coherent. Walls stay 1x1 to stress blocker updates.
Use the top-right control row for camera movement reminders and zoom buttons while you keep the map visible.
Hotkeys: 1 move, 2 land, 3 water, 4 wall, 5 erase wall.

Move the brawler or paint the map directly. Nav polygons appear while editing.
